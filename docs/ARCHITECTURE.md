# Архитектура Python-версии

HTML/Jinja + CSS + браузерный JavaScript → Flask JSON API → PyMongo → MongoDB replica set. Gunicorn запускает WSGI-приложение в production. Python обслуживает страницы, файлы и API без сборки клиентского кода.

norde/domain.py содержит расчёт аренды, календарные правила, переходы и нормализацию телефона; norde/validation.py — строгие проверки входных JSON. norde/app.py содержит маршруты и транзакции. norde/sessions.py реализует серверные сессии MongoDB: cookie содержит только подписанный непрозрачный ID, в базе хранится его SHA-256 и данные сеанса. Роль перечитывается из users на каждый запрос. После входа идентификатор и CSRF обновляются.

Бронирование сначала изменяет lockVersion автомобиля внутри транзакции, затем проверяет пересечения и сохраняет аренду с событием. PyMongo with_transaction повторяет конфликтующие транзакции. Та же запись автомобиля участвует в выдаче, возврате, архивировании и осмотрах. Соседние интервалы разрешены, незавершённая выдача блокирует другую.

Pillow проверяет реальное изображение, лимиты размера и разрешения, выполняет поворот и сохраняет WebP. В MongoDB — пути, сами фотографии — uploads. Резервное копирование включает оба хранилища.

Полная версия использует bcrypt и server-side sessions, HttpOnly/SameSite cookies, Secure в production, CSRF, строгие поля и роли. Демоверсия использует browser storage и не является серверной моделью безопасности.

Проверены 15 функциональных случаев Python/Selenium, 15 HTTP-сценариев коллекции Postman, 12 коротких нагрузочных повторов. Отказоустойчивый кластер, многочасовой стресс, реальный мобильный телефон, банковская оплата и восстановление пароля в этот объём не входят.
