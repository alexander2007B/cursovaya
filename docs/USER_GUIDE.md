# Руководство пользователя

## Клиент
1. Откройте «Автомобили». Можно выбрать класс, даты, марку и порядок сортировки.
2. Откройте карточку, проверьте характеристики и занятые периоды. Выберите даты и дополнительные услуги.
3. Нажмите «Забронировать». Если вход не выполнен, откроется форма входа/регистрации. После входа повторно отправьте заявку.
4. В «Мои поездки» заявка сначала имеет статус «Новая». Менеджер переводит её в «Подтверждена».
5. До выдачи заявку можно отменить. Дата возврата не включается в расчёт суток. Оплата происходит при получении, на сайте деньги не списываются.
6. Имя и телефон редактируются справа в профиле. Email в интерфейсе не меняется.

## Менеджер
1. Войдите под учётной записью сотрудника и откройте «Управление».
2. В разделе «Бронирования» подтвердите заявку. «Выдать авто» доступно на сервере только в период аренды и при отсутствии другой активной выдачи.
3. При возврате нажмите «Принять авто», укажите показания одометра, завершите аренду.
4. В «Автопарк» измените технический статус. При незавершённых заявках отправка в ремонт запрещена: сначала урегулируйте заявки.
5. В «Техобслуживание» внесите узел, износ, пробег и заключение. Осмотр сам по себе не меняет технический статус.
6. CSV скачивается из раздела бронирований. Журнал событий показывает последние 50 операций.

## Администратор
Администратор выполняет действия менеджера и дополнительно добавляет машины, меняет тарифы и характеристики, архивирует машины без незавершённых заявок и назначает роли. Удаление из каталога — логическое архивирование; история сохраняется. Собственную роль изменить нельзя.

## Запуск и типовые проблемы
- Ошибка соединения с MongoDB: выполните `npm run db:up`, проверьте `docker compose ps` и MONGODB_URI.
- «Transaction numbers ... replica set»: запущен standalone MongoDB. Используйте Compose проекта или кластер с поддержкой транзакций.
- Сессия устарела: обновите страницу, войдите повторно. Токен заменяется при входе.
- Автомобиль занят: выберите другие даты. Новые неподтверждённые заявки тоже резервируют интервал.
- Не уменьшается пробег: это инвариант системы; при ошибочных исходных данных нужна отдельная административная процедура исправления с аудитом.
- Записка: откройте Word/PDF из `docs/coursework`. Поля титульного листа, которые пользователь не предоставил, оставлены пустыми.
