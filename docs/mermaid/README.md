# Mermaid: Python-версия

.mmd — исходники функциональных схем, потоков, последовательности, ролей и данных. .png/.svg находятся в docs/diagrams. Они экспортированы движком Mermaid в настоящем Chromium, без генератора картинок.

Для редактирования можно открыть .mmd в Mermaid Live и экспортировать SVG/PNG. Дополнительный scripts/render-mermaid-local.py принимает MERMAID_DIST — каталог уже загруженных браузерных модулей Mermaid. Он использует Python, Selenium и локальную HTTP-страницу, не требует сборки сайта. Готовые изображения включены в комплект.

Функциональные схемы показывают входы, выходы, управление и механизмы IDEF0. Mermaid не является специализированным редактором строгой нотации IDEF0. Схема вариантов использования построена средствами flowchart.
