# Схемы Mermaid

Исходники .mmd соответствуют процессам, данным и архитектуре проекта. PNG и SVG экспортированы из Mermaid в реальном Chromium через Selenium на локальной странице. Это программные диаграммы, не фотографии и не изображения генератора картинок.

Контекст и декомпозиции показывают семантику IDEF0 (входы, выходы, управление, механизмы). Mermaid не поддерживает строгую нотацию IDEF0; поэтому рисунки являются функциональными схемами на её основе. Схема вариантов использования построена доступными средствами flowchart.

Движок установлен через @mermaid-js/mermaid-cli. Локальный экспорт CLI через file:// оказался заблокирован политикой браузера; использована собственная локальная страница HTTP с модулем mermaid.esm.min.mjs. Исходники схем и SVG сохранены для редактирования.
