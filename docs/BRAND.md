# NORDÉ: визуальный стиль Python-версии

Светлая тема, приглушённый голубой фон, крупная округлая шапка и контрастный акцент. Логотип NORDÉ и фотографии автомобилей сохранены. Шрифты Manrope находятся локально в static/fonts с лицензией.

Шаблоны Jinja размещены в templates/, стили - static/css/, интерактивность - static/js/app.js. На главной показываются только Mercedes-Benz GLB 200, Geely Cityray, Audi A5, BMW 520d xDrive, BMW M4 Competition и Mercedes-Benz CLS 250 d, доступные на выбранные даты. Общие шапка и подвал используются клиентскими страницами; шапка сохранена в рабочей панели.

Свежие изображения: docs/screenshots/coursework. Начальный автопарк полной версии: data/fleet.json. Пользовательские фотографии загружаются через API и не требуют пересборки приложения.
