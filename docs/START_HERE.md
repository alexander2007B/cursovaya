# NORDÉ: полная инструкция

Проект состоит из сайта, сервера и MongoDB. Открытие `index.html` двойным щелчком не запускает приложение. Ниже описан локальный запуск на вашем компьютере. Внешний домен и размещение сайта в интернете для защиты курсовой не нужны.

## Самый простой вариант: сначала оценить дизайн

Docker пока не нужен. Установите Node.js, скачайте актуальный ZIP из main, распакуйте и откройте папку в VS Code. В терминале выполните `npm.cmd ci`, затем `npm.cmd run demo`. Откройте на своём компьютере `http://localhost:5173`. Используйте учебные логины из раздела 4. После перезагрузки данные сохраняются в этом браузере; кнопка сверху сбрасывает демо. Для разных ролей используйте обычные вкладки и обновляйте страницу после действий в другой вкладке. В инкогнито хранилище отдельное. Настоящие данные сюда вводить не нужно: режим предназначен для оценки интерфейса, не обеспечивает серверную защиту и не проверяет реальные транзакции MongoDB.

Для сервера с базой используйте дальнейшие шаги. Демо-заявки автоматически не переносятся.

## 1. Скачать проект

1. Откройте https://github.com/alexander2007B/cursovaya под своим аккаунтом GitHub.
2. Выберите ветку `main`.
3. Нажмите зелёную кнопку **Code → Download ZIP**.
4. Распакуйте ZIP в обычную папку, например `C:\Projects\cursovaya-main`. Не работайте прямо внутри архива.
5. Откройте эту папку в Visual Studio Code: **Файл → Открыть папку**.
6. Выберите **Терминал → Создать терминал**. В текущей папке должен лежать `package.json`.

Если Git уже установлен, вместо ZIP можно выполнить:

```bash
git clone https://github.com/alexander2007B/cursovaya.git
cd cursovaya
```

## 2. Установить программы

- **Node.js 24 LTS**: https://nodejs.org/ . Поддерживается Node.js 22 и новее; используйте LTS. npm устанавливается вместе с Node.js.
- **Docker Desktop**: https://www.docker.com/products/docker-desktop/ . В Windows используйте Linux containers и рекомендованный Docker Desktop движок WSL 2. Если установщик просит включить WSL/виртуализацию, выполните его указания и перезагрузите компьютер.
- **Visual Studio Code**: https://code.visualstudio.com/ — удобен для редактирования, но сайт можно запускать из обычного терминала.
- **Google Chrome или Edge** — для работы с сайтом.
- **MongoDB Compass** — необязателен, нужен только для просмотра документов базы в графическом интерфейсе.

Отдельно устанавливать MongoDB Server не нужно: его запустит Docker. После установки Node.js закройте и снова откройте терминал. Откройте Docker Desktop и дождитесь запуска движка.

Проверьте:

```bash
node -v
npm -v
docker --version
docker compose version
```

Если PowerShell запрещает запуск `npm.ps1`, используйте `npm.cmd` вместо `npm` либо откройте терминал **Command Prompt / Командная строка** в VS Code. Менять системную политику выполнения скриптов не обязательно.

## 3. Первый запуск

Выполняйте команды по очереди из корня проекта. Если команда завершилась ошибкой, сначала устраните её — не переходите к следующему шагу.

```bash
npm ci
npm run setup:env
npm run db:up
npm run seed
npm run build
npm start
```

Назначение команд:

| Команда | Что делает |
|---|---|
| `npm ci` | Устанавливает версии зависимостей из package-lock.json |
| `npm run setup:env` | Создаёт локальный `.env` со случайным секретом сессии; существующий файл не меняет |
| `npm run db:up` | Запускает MongoDB в Docker, включает replica set и ждёт готовности |
| `npm run seed` | Добавляет восемь учебных автомобилей и три аккаунта; существующие данные сохраняет |
| `npm run build` | Собирает клиентский интерфейс в `dist` |
| `npm start` | Запускает сервер сайта на порту 3000 |

Первое скачивание образа MongoDB может занять несколько минут. Успешный запуск сервера сопровождается сообщением «АВТОБАЗА: сервер запущен, порт 3000, MongoDB подключена». Терминал после этого остаётся занят — это нормально. Не закрывайте его во время работы.

В адресной строке браузера **на этом же компьютере** введите `http://localhost:3000`. Это адрес локально запущенной программы, он не является общедоступным адресом сайта. Главная страница находится на `/`, каталог — `/catalog`, кабинет — `/account`, управление — `/admin`.

Альтернатива для Linux/macOS или Git Bash: `bash scripts/setup.sh`, затем `npm start`. Этот скрипт делает установку, настройку, запуск БД, seed и сборку. Обычный Windows PowerShell не выполняет bash-скрипты без установленного Bash; основные команды выше работают без него.

## 4. Аккаунты и вход

На сайте нажмите **Войти**. Используйте один из учебных аккаунтов:

| Роль | Email | Пароль |
|---|---|---|
| Клиент | `client@avtobaza.test` | `Avtobaza2026!` |
| Менеджер | `manager@avtobaza.test` | `Avtobaza2026!` |
| Администратор | `admin@avtobaza.test` | `Avtobaza2026!` |

Регистрируя нового пользователя, вы создаёте клиента. Администратор может назначить ему другую роль в панели. Пароли учебных аккаунтов открыто указаны специально для локальной демонстрации. Они не подходят для публичного сервера.

Для одновременной работы клиентом и сотрудником откройте обычное окно браузера и окно **Инкогнито / InPrivate**. В первом войдите клиентом, во втором — менеджером или администратором. Две обычные вкладки одного браузера используют общую сессию.

## 5. Работа клиента

1. Откройте **Автомобили**.
2. Выберите класс, при необходимости введите марку или модель и даты, нажмите **Подобрать**. Можно изменить сортировку.
3. Откройте карточку автомобиля. Прочитайте описание, тариф, залог и занятые периоды.
4. Укажите начало и возврат. Срок — от 1 до 30 суток, начало не раньше текущего дня. День возврата в число оплачиваемых суток не включается: с 10-го до 13-го — 3 суток.
5. Выберите дополнительные услуги. Защита — 600 ₽ в сутки, кресло — 300 ₽ в сутки. От 7 суток действует скидка 10% на базовую стоимость.
6. Проверьте итог. Залог показан отдельно. Добавьте комментарий, если нужен.
7. Нажмите **Забронировать**. Если открылось окно входа, войдите и повторно нажмите кнопку бронирования.
8. Откройте **Мои поездки**. Заявка сначала будет «Новая», затем после решения сотрудника — «Подтверждена».
9. Новую или подтверждённую заявку можно отменить. Для изменения дат отмените её и создайте другую.
10. В профиле можно изменить имя и телефон. Изменение email и восстановление пароля в текущей версии не реализованы.

Заявки и изменения сохраняются на сервере в MongoDB, поэтому не исчезают после обновления страницы. Новая неподтверждённая заявка тоже занимает даты. На сайте не списываются деньги: оплату и документы предполагается обрабатывать при получении автомобиля.

## 6. Работа менеджера

После входа откройте **Управление**.

### Бронирования

1. Найдите новую заявку, проверьте клиента, автомобиль, период и комментарий.
2. Нажмите **Подтвердить**.
3. В дату начала аренды нажмите **Выдать авто**. Ранняя выдача, выдача после окончания периода или выдача уже занятой машины отклоняется сервером.
4. После возвращения нажмите **Принять авто**, укажите пробег и **Завершить аренду**.
5. Пробег нельзя уменьшать. История переходов сохранится в заявке.
6. Кнопка **CSV** выгружает список заявок для просмотра в Excel/другом табличном редакторе.

### Техническое состояние

1. В **Техобслуживание** нажмите **Новый осмотр**.
2. Выберите автомобиль и узел: двигатель, тормоза, подвеска, шины, кузов или плановое ТО.
3. Введите износ от 0 до 100%, текущий пробег и результат осмотра.
4. Сохраните запись. Она появится в истории с датой и автором.
5. При необходимости в **Автопарк** измените технический статус на «На обслуживании» или «Неисправен».

Осмотр не переключает статус автоматически. Снять машину с выдачи нельзя, пока есть новые, подтверждённые или активные аренды: сначала отмените ожидающие заявки или оформите возврат активной машины. Состояние «В аренде» рассчитывается из активной аренды, вручную его назначать не нужно.

## 7. Работа администратора

Администратор может выполнять всё, что делает менеджер, а также:

- **Автопарк → Добавить автомобиль**: указать марку, модель, год, госномер, класс, тариф, залог, пробег, места, коробку, топливо, описание и технический статус.
- Кнопка с карандашом: изменить характеристики и тариф. Новый тариф влияет на будущие заявки; старые сохраняют первоначальный расчёт.
- Кнопка архива: убрать автомобиль из каталога. Действие требует подтверждения и разрешается только без незавершённых аренд. История сохраняется.
- **Пользователи**: назначить клиенту роль менеджера или администратора. Свою роль изменить нельзя.
- **Журнал событий**: посмотреть последние 50 записей об операциях.

В карточках используются локальные иллюстрации классов, а не фотографии конкретных автомобилей. Встроенной загрузки фотографий пока нет.

## 8. Как посмотреть MongoDB

В MongoDB Compass создайте соединение со строкой:

```text
mongodb://127.0.0.1:27017/avtobaza?replicaSet=rs0&directConnection=true
```

Откройте базу `avtobaza`. Основные коллекции:

- `users` — пользователи и хеши паролей;
- `cars` — автомобили;
- `rentals` — заявки, стоимость и история статусов;
- `maintenances` — осмотры;
- `events` — события;
- `sessions` — серверные сессии.

Для демонстрации можно создать заявку через сайт и обновить `rentals` в Compass. Не редактируйте вручную роли, суммы и статусы: прямое изменение обходит проверки приложения.

Данные находятся в Docker volume. Они сохраняются после остановки сайта и контейнера. Не выполняйте `docker compose down -v` и не удаляйте volume в Docker Desktop, если хотите сохранить данные.

## 9. Остановка и следующий запуск

Остановить сервер: нажмите **Ctrl+C** в терминале с `npm start`.

Остановить MongoDB без удаления данных:

```bash
npm run db:down
```

При следующем запуске откройте Docker Desktop, затем выполните:

```bash
npm run db:up
npm start
```

Повторно устанавливать зависимости и добавлять учебные записи каждый раз не нужно. Если изменились исходники интерфейса, перед `npm start` выполните `npm run build`.

## 10. Как изменять сайт

Для разработки запустите:

```bash
npm run db:up
npm run dev
```

Откройте в браузере на своём компьютере адрес с портом **5173**. Vite автоматически обновляет страницу после изменения клиентских файлов, сервер работает на порту 3000. Не держите одновременно `npm start` и `npm run dev`: оба пытаются занять порт 3000.

| Где менять | Файлы |
|---|---|
| Страницы, формы, навигация | `client/src/main.jsx` |
| Цвета, размеры, адаптивность | `client/src/styles.css` |
| Общение с API, отображение сумм и дат | `client/src/api.js` |
| Иллюстрации | `client/public/images/` |
| API, проверки доступа, действия | `server/app.js` |
| Расчёт стоимости и переходы статусов | `server/domain.js` |
| Модели и индексы MongoDB | `server/models.js` |
| Начальные учебные данные | `scripts/seed.js` |

Изменение seed не переписывает уже существующие машины и аккаунты. Меняйте текущие записи через админ-панель. Удалять базу ради изменения тарифа не требуется.

## 11. Тестирование и демонстрация на защите

При запущенной MongoDB:

```bash
npm test
npm run test:coverage
npm run build
npx playwright install chromium
npm run test:e2e
```

Проверяются 4 модульных, 18 интеграционных и 5 браузерных сценариев. E2E сами запускают выделенный сервер на порту 3001. Интеграционные базы `avtobaza_test_<pid>` и браузерная `avtobaza_e2e` предназначены только для тестов; не храните в них свои данные.

Для локальной нагрузки оставьте основной сервер работающим и выполните в другом терминале:

```bash
npm run test:load
```

Команда обновляет `docs/reports/load.json`. Результаты на вашем компьютере могут отличаться от приведённых в курсовой.

Порядок показа преподавателю:

1. Главная страница и каталог; показать фильтры и карточку.
2. Расчёт стоимости с услугами, вход клиентом, оформление на текущую дату.
3. Во втором независимом окне вход менеджером: подтверждение, выдача, возврат.
4. В первом окне обновить кабинет и показать завершённую аренду.
5. Осмотр и технический статус, управление тарифами администратором.
6. MongoDB Compass: показать сохранённые документы.
7. Запустить тесты, объяснить защиту от двойного бронирования.

Учебная установка не включает банковские платежи, рассылки, автоматическую проверку документов и восстановление пароля. Публичное развёртывание требует отдельной защищённой конфигурации, а GitHub хранит исходники: GitHub Pages не запускает Express и MongoDB.

- `docs/coursework/coursework.md` — исходный текст для пересборки.
- `docs/coursework/coursework-final.md` — текст с подставленными метриками.

- `docs/screenshots/` — скриншоты.
- `docs/reports/` — результаты проверок.

На титуле указаны ВКСИИТ и Баев Александр. Группа, специальность и руководитель оставлены пустыми по вашей просьбе. Перед сдачей заполните их и проверьте требования преподавателя к оформлению. При ручном изменении Word номера страниц в содержании могут потребовать исправления: текущее содержание сформировано по приложенному PDF.

Для изменения только текста можно редактировать Word. Автоматическая пересборка выполняется `bash scripts/render_coursework.sh`, но требует Python с python-docx, matplotlib и Pillow, Graphviz, LibreOffice и pdftotext. Для обычного запуска сайта эти программы не нужны.

## 13. Частые ошибки

| Симптом | Что сделать |
|---|---|
| `node` или `npm` не найдены | Установить Node.js, переоткрыть терминал |
| PowerShell блокирует `npm.ps1` | Запускать `npm.cmd` либо переключиться на Command Prompt |
| Не найден `package.json` | Перейти в распакованную папку проекта |
| Docker daemon / engine недоступен | Запустить Docker Desktop, дождаться готовности |
| MongoDB не подключается | `npm run db:up`, затем `docker compose ps`; проверить `.env` |
| Порт 27017 занят | Остановить другой локальный MongoDB или контейнер, который занимает этот порт |
| Порт 3000 занят / EADDRINUSE | Закрыть ранее запущенный сервер; не запускать start и dev одновременно |
| Ошибка SESSION_SECRET | Выполнить `npm run setup:env`; если старый `.env` уже есть, исправить в нём секрет — скрипт его не заменяет |
| Пустой каталог | Выполнить `npm run seed`, сбросить фильтры дат и класса |
| Transaction numbers / replica set | Использовать MongoDB из Compose проекта; standalone не поддерживает эти транзакции |
| Не удаётся выдать авто | Проверить период, технический статус и наличие другой активной аренды |
| Не удаётся отправить авто на ТО | Отменить ожидающие заявки, оформить возврат активной аренды |
| Сессия устарела | Обновить страницу, войти снова |
| После правок нет изменений | Для `npm start` пересобрать `npm run build`; либо использовать `npm run dev` |
| Word/PDF не открывается в GitHub | Скачать файл кнопкой Download raw file либо скачать весь репозиторий ZIP |

Для диагностики MongoDB можно выполнить `docker compose logs --tail=80 mongo`. Если нужна помощь, сообщите команду и текст ошибки; содержимое `.env` и личные пароли отправлять не нужно.

## Обновлённый дизайн и фотографии

Скачайте свежий ZIP в отдельную папку. Убедитесь, что терминал открыт в папке с `package.json`. Выполните `npm.cmd ci`, затем `npm.cmd run demo`. Docker и MongoDB для этого не нужны.

Для замены фотографии войдите как администратор, откройте «Управление → Автопарк», нажмите кнопку изменения автомобиля, выберите фотографию, дождитесь обработки и сохраните автомобиль. Подробности и допустимые источники: [PHOTOS.md](PHOTOS.md).

## Регистрация и темы

При регистрации укажите стаж в полных годах (минимум 1) и отметьте «Мне исполнился 21 год» и «У меня есть действующие водительские права». Это подтверждения пользователя; документы проверяет менеджер при выдаче. Старые аккаунты заполняют эти поля в личном кабинете перед следующим бронированием. Пересоздавать базу или сбрасывать демо не требуется.

Если гость нажимает «Забронировать», открывается регистрация с вкладкой входа для существующих клиентов. Выбранные автомобиль, даты и услуги остаются на странице. После регистрации нажмите «Забронировать» ещё раз: заявка не отправляется автоматически.

Кнопка с луной/солнцем в шапке переключает тему. Выбор сохраняется в этом браузере. Светлая палитра: #0593c6, #fcffff, #db3996; тёмная: #0a1430, #0297de, #fc734d. Для текста и второстепенных поверхностей используются дополнительные нейтральные оттенки.
