# С чего начать

Актуальная версия полностью запускается на Python. Откройте [README](../README.md) для локального запуска, [RENDER_PYTHON](RENDER_PYTHON.md) для Web Service и [TESTING](TESTING.md) для тестов. [Курсовая и руководства](coursework-30/README.md).

Не выполняйте прежние команды сборки интерфейса. Установите requirements.txt в Python-окружение и запустите app.py. Для общей базы дополнительно нужны MongoDB replica set и APP_MODE=full. Демо без базы сохраняет заявки в браузере.
