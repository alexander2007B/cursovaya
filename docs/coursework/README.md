# Актуальная пояснительная записка NORDÉ

- [Word — Baev_NORDE.docx](Baev_NORDE.docx)
- [PDF — Baev_NORDE.pdf](Baev_NORDE.pdf)
- [Параметры оформления и проверка](FORMAT_COMPLIANCE.md)
- [Автоматический протокол проверки](format-validation.json)

Документ подготовлен по двум предоставленным файлам: методическим рекомендациям ПиТПМ и Положению о курсовом проектировании ВКСИИТ. Основной источник для редактирования — coursework.md. Файл coursework-final.md содержит развёрнутые версии зависимостей и номера рисунков. Прежние файлы Baev_Avtobaza относятся к ранней версии и не являются итоговым документом.

На титуле заполнены колледж, МДК, тема, имя «Баев Александр», город и год. Группа, специальность, руководитель, нормоконтролёр, подписи и дата оставлены для заполнения. Демонстрационные сведения владельца сайта не использовались как подтверждённое отчество студента.

В Word встроены XO Thames Regular и Bold из официального пакета МойОфис; PDF также содержит встроенный шрифт. Если конкретный редактор игнорирует встроенные шрифты, установите XO Thames 1.1 с https://myoffice.ru/products/fonts/ . Для сверки окончательного вида используйте PDF. После ручного изменения Word обновите содержание и снова проверьте пагинацию.

Для повторной сборки нужны python-docx, Pillow, lxml, PyMuPDF, fontTools, Graphviz, Matplotlib, LibreOffice и XO Thames. Скрипт scripts/render_coursework.sh собирает документ и уточняет номера страниц содержания по PDF. scripts/validate_coursework.py проверяет поля, стили, кегль, шрифт в PDF, подписи, ссылки и геометрию текста.

Фактические тесты и измерения окончательной версии находятся в docs/reports/norde-final/. Исторический красный прогон двух ошибок валидации сохранён отдельно в docs/reports/tdd-validation-red.txt. Статистические значения в записке не являются характеристиками промышленной установки.
