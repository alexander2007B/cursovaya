# Подготовка защиты Python-версии

Используйте пояснительную записку и руководства из docs/coursework-30. Покажите архитектуру Flask/Jinja/PyMongo, модель коллекций, расчёт Python и конкурирующее бронирование. На локальном полном режиме пройдите клиент → менеджер → возврат с пробегом. Затем откройте pytest, Selenium, коллекцию Postman и реальные протоколы Python-версии.

Демо служит показом интерфейса и не доказывает транзакции MongoDB. Нагрузочный опыт относится к локальному чтению каталога. Подписи и даты сдачи на титуле заполняются при сдаче; вопрос о прекращении нумерации после заключения ранее не был уточнён.
