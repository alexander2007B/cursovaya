# Готовность NORDÉ к защите

Проверка по приложенной методичке ПиТПМ, 6 ноября 2026 года. Это план подготовки, а не гарантия оценки.

## Основной вывод

Функциональная основа уже есть. Следующий этап — воспроизводимый запуск с настоящей MongoDB на компьютере для защиты, актуальные доказательства тестирования и согласованная с сайтом записка. Демо в браузере предназначено для просмотра интерфейса.

## Что реализовано

- React → Express API → MongoDB/Mongoose. Коллекции users, cars, rentals, maintenances, events и sessions.
- Клиент, менеджер и администратор с проверкой прав на сервере. Пароли хешируются; серверные сессии и CSRF-защита.
- Регистрация с возрастом, правами и стажем; каталог, даты, расчёт суммы и залога, заявка, отмена, личный кабинет.
- Подтверждение, выдача и возврат автомобиля, обновление пробега, техническое обслуживание, архивирование, роли и журнал операций.
- Индексы, транзакции и проверка пересечений аренды защищают от двойного бронирования. Для этого MongoDB должна поддерживать транзакции: используется replica set.
- 12 учебных машин с фото, галереи, карусель, поиск, избранное браузера, постоянное хранилище серверных данных в полном режиме.

Методичка явно требует базу данных, TDD, E2E и нагрузочные испытания; минимум 25 страниц без приложений. Также указаны IDEF0 (три уровня), DFD и UML: классы, use case, sequence, activity. Диаграммы и отчёты в репозитории уже есть, но после изменений необходимо сверить их с итоговой версией. Доказательства TDD должны отражать реальные шаги разработки; нельзя выдавать задним числом придуманные «падающие тесты» за историю работы.

## Запуск с MongoDB

Пошаговый порядок находится в [START_HERE.md](START_HERE.md#3-первый-запуск). Через Docker Compose MongoDB поднимается локально как replica set, данные сохраняются в volume. При остановке не удаляйте volume: `docker compose down -v` удаляет базу.

Если Docker на Windows остаётся проблемой, сервер может работать с MongoDB Atlas через MONGODB_URI. Нужны интернет и настройка доступа к кластеру. Для защиты без зависимости от интернета предпочтительна локальная установка. Обычная standalone MongoDB не подходит для используемых транзакций без настройки replica set.

В MongoDB Compass полезно показать users, cars и rentals и объяснить ссылки user/car, снимок тарифа, индексы и вложенную историю. Фотографии хранятся файлами, в базе — пути. В резервную копию включают базу и uploads/; код и учебные изображения находятся в репозитории.

## Ограничения, которые нужно уметь объяснить

Это учебный сервис: нет банковского эквайринга, автоматической проверки прав и документов, восстановления пароля и почтовых уведомлений. Флажки возраста/прав — подтверждение пользователя; документы проверяет менеджер при выдаче. Контакты и автопарк демонстрационные. Избранное хранится в браузере. Эти ограничения стоит описать в записке как границы проекта, а не обещать реализованный функционал.

Для курсовой полезнее отработать существующий процесс и доказать его корректность, чем расширять интерфейс новыми неподготовленными функциями. Окончательную оценку определяют требования преподавателя, оформление и защита.
