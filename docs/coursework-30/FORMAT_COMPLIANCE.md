# Оформление редакции Python

Сохранены пользовательские уточнения: Times New Roman 12 пт; поля 3/1,5/2/2 см; заголовки разделов по центру прописными; подразделы с отступом 1,25 см, одинарным интервалом и отбивками; библиография по ширине с красной строкой и интервалом 1,25. Источники упорядочены по нормативным документам, русскоязычным и англоязычным ресурсам. Условные даты обращения заданны пользователем, фактическая история посещений не восстанавливалась.

Таблицы: шапка по центру, первый столбец слева, остальные по центру; одинарный интервал. Большая таблица имеет явный перенос с повтором шапки, небольшие удерживаются целиком. Рисунки следуют после текстовой ссылки, имеют рамку и подпись снизу. Приложение 1 с новой страницы, номер справа и название по центру; приложение 2 удалено.

Титульник соответствует образцу из предоставленного Положения с пользовательским названием и А.И. Трофимовой. Подписи и даты сдачи не подставлены. Неуточнённым остаётся прежний вопрос о прекращении нумерации после заключения.

Методичка допускает уточнения по МДК: три раздела сохранены по подтверждению пользователя. Локальный PDF-просмотр использует замену отсутствующего Times New Roman; окончательные переносы следует проверить в Microsoft Word. Отчёт norm-review-draft.json содержит автоматическую геометрическую и структурную проверку, не заменяющую подпись нормоконтролёра.
