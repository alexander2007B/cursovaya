Нормоконтролёр пока не известен. Подписи и даты сдачи не подставлены. Реквизиты вынесены в title-data.json.

Для всех 24 источников проверена доступность, дата обращения обновлена на 26.11.2026. Годы публикации не придуманы: для части обновляемых сайтов требование о возрасте не старше пяти лет остаётся неподтверждённым; сведения проверки находятся в source-date-check.json.

Новый полный прогон от 26.11.2026: 15 функциональных случаев pytest (6 доменных, 5 интеграционных, 4 Selenium), 15 запросов / 15 утверждений Postman/Newman, четыре нагрузочных режима по три повтора. Все прошли. Локальная полная версия использует MongoDB; статический Render не нагружался. Старые протоколы от 06.11.2026 остались только в архивной папке docs/reports/norde-final.

Весь интерфейс снят заново Selenium. Отдельный [атлас экранов Word](manuals/UI_Atlas.docx) и [PDF](manuals/UI_Atlas.pdf) показывает 15 актуальных состояний; он не входит в 30 страниц основной записки. [Карта тестов](../TESTING.md) объясняет инструменты, файлы и запуск. Итоговые XML/JSON/TXT: docs/reports/selenium-pytest-postman/.

## Сборка

Основной исходник - coursework.md. Скрипты scripts/build_coursework_compact.py и scripts/render_coursework_compact.sh собирают Word/PDF и уточняют содержание. scripts/build_coursework_manuals.py собирает руководства из manuals/*.md. Python-зависимости перечислены в requirements-docs.txt; также нужны LibreOffice, Graphviz и установленный XO Thames. Для обновления снимков дополнительно нужны requirements-test.txt. Для встраивания шрифтов используется каталог .coursework-fonts/TTF рядом с корнем репозитория; копии шрифтов извлекаются из ранее подготовленного документа.
