# Курсовой проект NORDÉ — Python

Редакция 27.11.2026: Flask, Jinja, PyMongo, HTML/CSS и браузерный JavaScript. Установка и запуск не требуют Node.js или сборки интерфейса. Название, студент, группа, руководитель и нормоконтролёр сохранены по данным пользователя.

Текущие проверки: 15 функциональных случаев pytest, включая 4 Selenium; 15 HTTP-сценариев коллекции Postman, исполненных Python/Requests; четыре нагрузочных режима по три повтора. Протоколы docs/reports/python-final, отдельный реальный пример Red/Green — docs/reports/red-green.

Изображения интерфейса получены из работающей Python-версии. Схемы Mermaid соответствуют Flask/Jinja/PyMongo; .mmd и SVG доступны для редактирования. Снимок терминала получен из реального запроса к изолированной MongoDB. Изображения генератора картинок не используются.

Оформление: Times New Roman 12 пт, поля 3/1,5/2/2 см, подразделы с отступом 1,25 см и одинарным интервалом; библиография 1,25. Точное число страниц и результаты проверки находятся в norm-review-draft.json. На машине предварительного просмотра Times New Roman заменяется метрически совместимым шрифтом; окончательные переносы нужно проверить в Microsoft Word.

Даты обращений в библиографии являются условной хронологией, заданной пользователем для оформления, а не восстановленной историей посещений. Неподтверждённые годы публикации не придуманы. Подписи и даты сдачи остаются пустыми; прежнее замечание о прекращении нумерации после заключения пока не уточнено.

Новая Python-версия не означает автоматического изменения прежнего Render Static Site: нужен отдельный Web Service. Настройки находятся в docs/RENDER_PYTHON.md.
