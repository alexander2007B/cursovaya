# Перенос с прежней серверной версии

Python использует существующие users, cars, rentals, maintenances и events. Поля _id, ссылки ObjectId, вложенные quote/history/legal, даты и bcrypt-хеши совместимы. Никакого удаления пользовательских записей или переименования коллекций не выполняется. Новый слой сессий хранится в python_sessions с TTL; это требует повторного входа, но не удаления пользователей.

1. Сделайте резервную копию MongoDB и uploads до переключения.
2. Укажите старый MONGODB_URI и новый случайный SESSION_SECRET в защищённом .env.
3. Включите APP_MODE=full; для публичного HTTPS — APP_ENV=production.
4. Запустите Python и проверьте вход прежней учётной записью, список машин, старые заявки, статусы и фотографии.
5. Сначала проверьте перенос на копии базы. Не запускайте scripts.test_server с рабочими данными: его изолированная база предназначена для удаления при тестах.

Seed не нужен для существующей базы. Он разрешён только для учебной локальной установки и вставляет недостающие записи. Смена технического статуса и архивирование по-прежнему запрещены при незавершённых арендах. Транзакции требуют replica set.

Демо хранит прежние ключи avtobaza-preview-v1 и avtobaza-preview-user, поэтому данные в том же origin сохраняются. При смене домена браузерное хранилище автоматически не переносится. Избранное использует прежний ключ norde-favorites. Данные из демо не импортируются в MongoDB автоматически.
