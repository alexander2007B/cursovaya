# АВТОБАЗА

Курсовой проект Баева Александра: **«Разработка и обеспечение качества информационной системы автоматизации аренды и учёта состояния автопарка»**.

Полноценное учебное веб-приложение: React + Express + MongoDB. Клиентская часть и панель сотрудников работают с одной реальной базой данных. В браузере не хранятся роли, пароли или заказы.

**Начните с [полной пошаговой инструкции](docs/START_HERE.md)**: установка на Windows, запуск, аккаунты, работа с арендой и решение ошибок.

## Быстрый запуск

Нужны **Node.js 22+**, **Docker с Compose** и свободные порты 3000, 27017.

```bash
npm ci
npm run setup:env
npm run db:up
npm run seed
npm run build
npm start
```

В браузере откройте порт **3000** на машине, где запущен сервер. Для разработки: `npm run dev` (Vite на порту 5173, API на 3000). Можно использовать `bash scripts/setup.sh`: он установит зависимости, создаст `.env`, если его нет, запустит MongoDB, добавит учебные данные и соберёт интерфейс.

MongoDB запускается как одноузловой replica set: это необходимо для транзакций. База хранится в Docker volume `mongo_data`. Команда `npm run db:down` останавливает БД и сохраняет данные. Не добавляйте `-v`, если хотите их сохранить. Образ MongoDB опубликован MongoDB, контрольные суммы проверяет Docker.

## Учебные аккаунты

Seed работает только вне production и при `SEED_DEMO=true`. Повторный запуск не заменяет существующие аккаунты, автомобили и осмотры.

| Роль | Email | Учебный пароль |
|---|---|---|
| Администратор | admin@avtobaza.test | Avtobaza2026! |
| Менеджер | manager@avtobaza.test | Avtobaza2026! |
| Клиент | client@avtobaza.test | Avtobaza2026! |

Это намеренно открытые **демонстрационные** реквизиты, не реальные секреты. Для публичного развёртывания используйте отдельную базу без этих аккаунтов, HTTPS, собственный SESSION_SECRET и MongoDB с аутентификацией. БД в Compose доступна только через loopback машины. Поле `NODE_ENV=production` включает Secure-cookie: нужен HTTPS. Приложение не публиковалось в интернете.

## Что работает

- Клиент: регистрация, вход, профиль, поиск и фильтры, характеристики, проверка доступности на даты, расчёт цены, услуги, бронирование, история и отмена.
- Менеджер: заявки, подтверждение, выдача, возврат с пробегом, технические статусы, осмотры, история изменений и CSV.
- Администратор: все функции менеджера, добавление/изменение/архивирование автомобилей, тарифы, назначение ролей.
- Сервер: MongoDB-транзакции против двойного бронирования, проверка ролей и владельца заявки, bcrypt, сессии в MongoDB, HttpOnly-cookie, CSRF, валидация, ограничение частоты входа.

Аренда — от 1 до 30 суток. Дата возврата не включается. Скидка на базовую аренду — 10% от 7 суток. Расширенная защита — 600 ₽/сутки, детское кресло — 300 ₽/сутки. Залог считается отдельно. Онлайн-оплаты, автоматической проверки документов, SMS/email-рассылок нет: договор, документы и оплата обрабатываются сотрудником при выдаче. Сумма завершённых аренд в панели не является подтверждённой банковской выручкой.

## Проверки

```bash
npm test                 # 4 unit + 18 интеграционных; нужна запущенная MongoDB
npm run test:coverage    # покрытие серверных модулей
npx playwright install chromium
npm run test:e2e         # 5 браузерных сценариев, собственный сервер :3001
npm run test:load        # запущенный основной сервер :3000; 10/50 соединений по 10 секунд
```

В облачной среде Chromium уже установлен: `PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`.

API-тесты создают отдельную БД `avtobaza_test_<pid>` и удаляют только её. E2E пересоздаёт **только** `avtobaza_e2e`, затем запускает отдельный сервер. Не храните личные данные в этих тестовых базах. Результаты: `docs/reports/`, HTML-отчёт E2E — `playwright-report/`.

## Структура

```text
client/src/       React-интерфейс, стили, клиент API
client/public/    локальные SVG-иллюстрации и шрифт Manrope (OFL)
server/          Express, модели MongoDB, расчёт аренды и статусы
scripts/         настройка, seed, нагрузка, скриншоты, сборка записки
tests/           unit, интеграционные, браузерные сценарии
docs/            архитектура, API, инструкции, схемы и отчёты
```

Пояснительная записка Word и PDF, исходный текст и материалы для защиты находятся в `docs/coursework/`. На титульном листе заполнены только подтверждённые данные; группа, специальность и руководитель оставлены пустыми. Документация описывает фактический объём проверок и ограничения, а не заявляет полную готовность к промышленной эксплуатации.
